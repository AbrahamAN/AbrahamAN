## 💼 A bit about my work

Most recently I've been part of the core team at **Banco Galicia** (via Baufest), one of Argentina's largest banks — working full-stack on financial products like mortgage loans, retail loans, and vehicle pawn. I've built both the React/Next.js frontends and the NestJS backend services, including authentication flows with JWT, role-based access control, and TypeORM-based data layers.

Before that, I led a full-stack migration from a legacy JS/PHP monolith to a modern React + TypeScript frontend and NestJS backend at a real estate CRM, and mentored junior developers along the way.

I'm comfortable making technical decisions on both sides of the stack, reviewing PRs, and helping teammates grow — not just shipping features.
